# Maintainers

ILM is developed across the repositories of the
[OmniTrustILM](https://github.com/OmniTrustILM) organization. The maintainers
listed here are responsible for the platform as a whole, not only for this
repository.

Areas describe the parts of the platform a maintainer reviews and merges:

- **Core** — core platform services, access control, scheduling, and API interfaces
- **Go** — components written in Go, including the command line interface, SDK, and operator
- **Infrastructure** — deployment tooling, container images, and release automation
- **UI** — web user interfaces and the design system

## Becoming a maintainer

Maintainers are appointed, step down, and move to emeritus status as described
in [GOVERNANCE.md](GOVERNANCE.md). If you would like to work towards becoming a
maintainer, start with the [contribution guide](CONTRIBUTING.md).

## Contacting the maintainers

- For questions, bug reports, and feature requests, open an issue in the
  relevant repository. See the [contribution guide](CONTRIBUTING.md).
- To report a security vulnerability, follow the
  [security policy](https://github.com/OmniTrustILM/.github/blob/main/SECURITY.md).
